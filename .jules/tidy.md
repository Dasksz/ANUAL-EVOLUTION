## 2026-07-31 : (Revert Frontend Chunking) **Aprendizado:** Enviar múltiplas requisições paralelas (Promise.all) de buscas globais pode sobrecarregar o pool de conexões do Supabase, gerando erros HTTP 500 e cancelamento por Timeout (57014), pois múltiplas queries pesadas tentam executar ao mesmo tempo. A base de dados geralmente é muito mais eficiente resolvendo uma única query agregada (que usa tabelas de resumo). **Ação:** Remover toda lógica de 'chunking' (fornecedores/filiais) no frontend ao chamar dashboards. Fazer apenas uma chamada à RPC passando nulo para trazer os resultados globais usando cache otimizado.
