## 2026-08-19 - Javascript Error Fixes
**Learning:** In large monolithic JS files, functions defined within a `DOMContentLoaded` block or later in the file are not hoisted to the global scope if accessed by asynchronous event callbacks (like auth listeners) that might trigger before the parser reaches the definition.
**Action:** Always ensure globally used helper functions (like loading overlays) are either explicitly hoisted to the top of the file (outside `DOMContentLoaded`) or properly modularized to prevent `TypeError: X is not a function`.
